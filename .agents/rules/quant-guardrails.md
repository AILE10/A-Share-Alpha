# A-Share Quant Studio 全局开发红线
1. 严禁 Mock 数据：数据拉取、因子计算、回测引擎与模拟盘模块禁止使用随机数或硬编码假数据冒充真实行情，必须接入真实 A 股接口（AKShare / Baostock，并预留 Tushare 适配器）且落盘本地 DuckDB/SQLite 缓存。
2. 严守 A 股交易约束：所有回测和模拟撮合必须强制执行 T+1（当日买入不可当日卖出）、100 股整数倍买入、主板 10% / 创业板科创板 20% / 北交所 30% 涨跌停板限制（涨停封板无法买入、跌停封板无法卖出）、前/后复权正确对齐、真实费用（佣金万1.5最低5元、卖出印花税0.05%、过户费、滑点）。
3. 严防未来函数与数据泄露：财务因子必须按财报实际公告日（ann_date）而非报告期（end_date）向后填充；机器学习训练必须采用 Purged Walk-Forward 滚动切分，训练集与测试集之间保留至少 5 个交易日隔离期（Embargo）。
4. 合规与风控底线：券商接口采用抽象 Adapter 模式，严禁编写逆向抓包或模拟点击外挂代码；任何交易信号进入执行层前必须经过前置风控中间件（单票仓位上限、行业集中度上限、组合回撤熔断、报撤单频率限流）。
5. 真实运行验证：每个里程碑完成后，必须通过终端运行 pytest 与真实小样本数据脚本验证输出，并在前端联调阶段通过浏览器检查页面渲染与控制台零报错。
