# 合规券商程序化交易接入指南（迅投 MiniQMT / 恒生 PTrade）

> **严正合规声明**：本系统严格遵守中国证监会《证券市场程序化交易管理规定（试行）》及沪深北交易所报备规范。`CompliantQMTAdapter` 仅通过券商官方授权客户端提供的 SDK 桥接，**严禁**任何逆向抓包、内存注入或模拟鼠标键盘外挂行为。

## 1. 接入前置条件

1. 向支持个人量化接口的合规券商（如国金、国信、华泰、银河等）申请开通 **迅投 MiniQMT（极简版）** 或 **恒生 PTrade** 程序化交易权限，并按监管要求完成程序化交易投资者报备。
2. 在本机（通常为 Windows 环境）安装券商官方提供的 MiniQMT 客户端并登录极简模式，获取本地 `userdata_mini` 目录路径与对应资金账号。
3. 将券商随客户端提供的官方 `xtquant` Python 包安装至 `backend/.venv` 环境。

## 2. 在工作台中配置与自检

1. 打开前端工作台第 6 页 **「券商网关与风控设置」**。
2. 填入 `MiniQMT userdata_mini 路径` 与 `券商资金账号`。
3. **首次接入务必保持 `Dry-Run 安全演练模式 = 开启`**：系统将执行全部前置风控校验（单票 ≤ 12%、单行业 ≤ 25%、回撤熔断、报撤频率限流），并生成标准 `xtquant` 委托载荷写入日志，但不向实盘发单。
4. 通过页面「环境自检」确认 `xtquant_installed`、`userdata_path_exists`、`account_id_configured` 全部为 `true` 后，方可按需关闭 Dry-Run。

## 3. 个人投资者推荐路径

未开通券商程序化权限前，推荐使用内置的 **半自动辅助模式（`ASSISTED`）**：
- 尾盘 `14:40` 自动通过企业微信/钉钉 Webhook 及前端弹窗推送标准交易单（含建议股数、参考价、止损位与 Top 3 因子归因）；
- 投资者在券商官方 App 人工核对下单后，通过弹窗或第 6 页「录入实盘成交」一键回写真实成交价与手续费，实现完整的实盘持仓与周度复盘闭环。
