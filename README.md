# A-Share Alpha Studio

面向个人投资者的 **A 股全栈实时量化投研、Purged Walk-Forward 回测优化、模拟实盘与合规辅助交易系统**。

> **免责声明**：本项目仅供个人量化研究与技术学习使用，不构成任何投资建议；内置所有券商接入均采用合规抽象 Adapter（模拟盘 / 人工确认辅助单 / 券商正规授权 QMT），严禁任何外挂或违规抓包。

## 一、核心策略与实证表现（Champion 1b 官方基准）

- **全真实 A 股数据源（零 Mock）**：免费免 Token 接入 AKShare 主源（腾讯日线 + 东财 PIT 财报与主力资金流 + 新浪日历/指数）+ Baostock 备用，预留 Tushare Pro 适配器，全部落盘本地 DuckDB 与 SQLite。
- **动态股票池与四维 20 因子库**：每日剔除 ST/*ST、停牌、次新（< 120 交易日）、近 20 日均成交 `< 5,000 万`、总市值后 `10%` 微盘股及 `< 2.5 元` 面值退市高危股；覆盖量价动量反转（含日内-隔夜聪明钱价差 `smart_intra_minus_on_20d`）、流动性与资金流、波动率与筹码结构（含距 120 日新高距离 `high_120d_prox`）、严格按财报真实公告日（`trade_date > ann_date`）对齐的 PIT 基本面，经 MAD 去极值 → 申万一级行业 + 对数市值 OLS 中性化 → 横截面 Z-Score。
- **严防未来函数的 Purged Walk-Forward LightGBM**：默认采用 **10 日超额收益 `Huber 回归` + `6-Seed Bagging` 截面集成**，强制 252 日滚动训练 + 10 日标签清洗（Purge）+ 10 日隔离期（Embargo），内置线性精确 **TreeSHAP** 归因与两级水位研究缓存。
- **Champion 1b 两大核心增强（经多起点漂移 / 跨持股数高原 / 双倍滑点严格验证）**：
  1. **强牛纯 120 日新高突破叠加（`OFFENSIVE` 专属）**：仅在大盘确认为强牛状态时，对个股模型分叠加 **`+0.25·z(距120日新高)`**，同时将易引发短线反转追高的 20 日动量权重清零（`0.00`）；震荡与熊市保持零干预，精准捕捉上方无套牢盘的主升浪领涨股；
  2. **抗锁仓 11%/12% 回撤风控**：将过敏感的 `-8% (半仓 50%)` 预警线优化为 **`-11%` 预警（温和降仓至 `70%`）**，解除牛市常规回撤被锁半仓的“手刹效应”，同时**死守 `-12%` 组合硬熔断红线、单票 `12%` 上限、单行业 `25%` 上限与个股 `-8%` 硬止损绝不放宽**。
- **高精度 A 股撮合与每日固定流程自动化**：强制 T+1、100 股整数倍、主板 10% / ST 5% / 创科 20% / 北交 30% 涨跌停封板顺延、次日开盘价真实跳空撮合、真实佣金/印花税/过户费/10bps 滑点，并内置 **5 步每日固定交易流程图与实时状态面板**。

## 二、小白保姆级使用说明：1 个月实盘模拟验证指南

如果你是第一次使用量化系统、准备用未来 **1 个月** 进行真实行情的实盘模拟验证，完全不需要懂复杂金融代码，按下面 4 步操作即可。

### 第 1 步：启动系统（开机/重启电脑后操作）

如后台未启动，打开两个终端（PowerShell）窗口分别运行以下两条命令，**保持窗口不要关闭**：

- **窗口 1（启动后端量化引擎，端口 `8000`）**：
  ```powershell
  cd backend
  .venv\Scripts\uvicorn.exe app.main:app --host 0.0.0.0 --port 8000
  ```
- **窗口 2（启动网页界面，端口 `5173`）**：
  ```powershell
  cd frontend
  npm run dev
  ```

启动后在浏览器打开 **`http://localhost:5173`** 即可进入量化工作台。

### 第 2 步：正式开跑前的一次性初始化（只需做 1 次）

1. **重置模拟盘本金（从今天干净记账）**：
   - 打开左侧菜单 **「模拟实盘与复盘」**（`http://localhost:5173/paper`），点击右上角红色按钮 **「重置模拟盘」**。
   - 输入你未来真实打算投入的模拟资金（**建议 ≥ 30 万元**，例如 `300000` 或 `500000`——策略最多持仓 10 只股票，受 A 股 100 股一手限制，本金过低容易导致高价优质股买不够一手）。
   - 点击 **「确认清空重置」**（仅清空模拟账本，不影响已下载的 4,111 只股票历史数据与已训练模型）。
2. **确认执行模式与手机通知（可选）**：
   - 进入 **「券商网关与风控」**（`http://localhost:5173/broker-risk`），保持模式为 **`PAPER 模拟盘`**（第 1 个月最推荐，全自动按真实 L1 卖一/买一盘口成交并核算真实费用与 T+1）。
   - 如希望手机收到每日调仓提醒，可在此页面填入企业微信或钉钉群机器人 Webhook URL，保存并点击 **「测试 Webhook 推送」**。

### 第 3 步：看懂系统内置的「每日固定 5 步流程图」

系统已在 **「策略总览与大盘」**（`/`）和 **「模拟实盘与复盘」**（`/paper`）页面集成 **每日固定交易流程实时状态面板**。只要交易日电脑与服务保持开启，内置 APScheduler 调度器会自动按顺序执行全部 5 步，每个节点会实时变绿显示 **执行时间、自动/手动来源与结果摘要**：

| 步骤 | 自动时间（交易日） | 系统自动执行内容 | 错过自动时间如何手动补跑 |
| :---: | :---: | :--- | :--- |
| **01** | **09:26** | **盘前 T+1 解锁**：将昨日买入的持仓解锁为今日可卖 | 在流程图节点 01 点 **「手动解锁」** |
| **02** | **09:30 ~ 14:55** | **盘中盯市与大盘扫描**：轮询实时盘口监测 `-8%` 硬止损 / ATR 止损，每 3 分钟刷新全市场大盘状态 | 在流程图节点 02 点 **「立即盯市」** |
| **03** | **14:40（核心）** | **14:40 选股与调仓**：结合实时大盘与 L1 盘口重算 6-Seed 推荐清单，经风控拦截后自动先卖后买 | 14:35~14:55 或收盘后在节点 03 点 **「立即调仓」** |
| **04** | **15:30** | **收盘同步与净值记账**：增量同步 4,111 只股票当日日线/指数/资金流，重算因子并记录当日净值曲线 | 15:35 后在节点 04 点 **「收盘同步」** |
| **05** | **周五 16:30** | **周度复盘与因子体检**：对比模拟实盘与理论回测跟踪误差、滑点损耗及 20 日因子衰减 | 随时可在节点 05 点 **「立即复盘」** |

#### 常见按钮答疑（小白必看）
- **「实时快照重算推荐清单」按钮（在「实时选股与 K 线」页）会改模型或下单吗？**
  - **完全不会！** 它只是只读预览，用当前已激活的模型和最新盘口价算一遍建议买/卖清单给你看，**不会重训模型、不会产生任何订单、不动用模拟资金**，最适合在 **14:30 ~ 14:38（自动调仓前预览）** 或 **15:35 收盘同步后** 随时点击查看。
- **为什么大盘显示 `弱势防守 (0%)` 时系统一股不买？**
  - 这是完全正常的保本机制！当中证 1000 处于弱势空头且全市场站上 20 日线宽度极低时，系统会严格空仓躲避暴跌（闲置现金实盘可配置货币 ETF / 国债逆回购）；一旦大盘反弹转强自动切换至 `震荡中性 (60%)` 或 `强势进攻 (95%)`，14:40 便会自动建仓。
- **验证期间需要更新模型吗？**
  - 建议每运行 **2 周（约 10 个交易日）**，在 **「模拟实盘与复盘 → 模型版本管理」** 点击一次一键滚动重训，吸收最新行情；历史版本均自动快照保留，随时可一键回滚。

### 第 4 步：1 个月实盘模拟结束后的 4 项验收标准

跑满 1 个月后，打开 **「模拟实盘与复盘 → 周度复盘与偏差归因」** 检查以下 4 点：
1. **实盘-回测跟踪误差**：1 个月模拟实盘收益与同期理论回测收益差距是否在 **`±1.5%`** 以内；
2. **滑点与涨跌停损耗**：真实 L1 卖一/买一吃单与涨跌停顺延带来的净收益损耗是否可控；
3. **纪律与风控执行**：遇到大盘转弱或个股破位时，是否全部按规则自动降仓/止损、无任何越界；
4. **实盘心理匹配度**：持仓节奏、换手频率与波动幅度是否让你能从容拿住、不手痒干预。

## 三、新电脑一键部署（3 种方式任选）

克隆仓库后无需任何付费 Token，**一条命令即可自动完成环境配置、依赖安装、真实 A 股初始化与前后端启动**：

### 方式 1：Windows 一键部署（推荐）
```powershell
git clone <你的仓库地址> a-share-alpha-studio
cd a-share-alpha-studio

# 快速部署（首次自动装依赖 + 拉取 60 只代表性真实 A 股 + 训练模型 + 启动工作台）
powershell -ExecutionPolicy Bypass -File scripts\deploy.ps1

# 如需全市场 4,100+ 活跃 A 股 + 回补至 2023-06-01（支持断点续传）
powershell -ExecutionPolicy Bypass -File scripts\deploy.ps1 -Mode full

# 日常仅启动前后端服务
powershell -ExecutionPolicy Bypass -File scripts\deploy.ps1 -Mode start
```

### 方式 2：macOS / Linux 一键部署
```bash
git clone <你的仓库地址> a-share-alpha-studio
cd a-share-alpha-studio
chmod +x scripts/deploy.sh

# 快速部署并启动
./scripts/deploy.sh

# 或全市场深度初始化
./scripts/deploy.sh full
```

### 方式 3：Docker Compose 容器化一键部署
```bash
git clone <你的仓库地址> a-share-alpha-studio
cd a-share-alpha-studio
docker compose up -d --build
```

启动完成后直接访问：
- **量化工作台前端**：`http://localhost:5173`
- **FastAPI 接口文档**：`http://localhost:8000/docs`

> **新电脑使用 Antigravity 打开本项目**：仓库内置 `.agents/plugins/a-share-alpha-studio/` 与 `.agents/rules/`，在新电脑用 Antigravity 打开后可自动加载全套量化红线与运维技能，详见 [BOOTSTRAP_ANTIGRAVITY.md](BOOTSTRAP_ANTIGRAVITY.md)。
